Teltonika Router Setup

For Teltonika RUT/RUTX routers running RutOS, copy or download this UCI configuration script. SSH into the router and run it to configure WireGuard with 1:1 NETMAP.

#!/bin/sh
# Teltonika RutOS WireGuard Configuration Script
# Site tunnel IP: {{ site.wg_tunnel_ip }}
# Virtual subnet: {{ site.virtual_subnet }} -> Local subnet: {{ site.local_subnet }}
# Download the full script: /sites/{{ site.id }}/teltonika.txt
Download Script
  1. Download the script using the button above
  2. SSH into your Teltonika router: ssh root@192.168.1.1
  3. Upload and run the script: sh /tmp/{{ site.site_code }}-teltonika.txt
  4. The router will restart networking and firewall services
  5. Verify the tunnel is up: wg show

Note: The script configures 1:1 NETMAP so devices at {{ site.local_subnet }} become reachable at {{ site.virtual_subnet }}.
