How it works

Operators provision sites on the hub. Edge gear joins with WireGuard, Tailscale (Headscale), or OpenVPN. Techs dial into the hub and open virtual IPs from the cheat sheet.

  1. 01

    Allocate

    Each site gets the next 10.101.X.0/24. Local .Y maps 1:1 to virtual .Y.

  2. 02

    Connect the edge

    Gateway router for a full LAN, or a direct WireGuard install on a Pi / cloud VM — including a 3‑minute curl | sudo bash link.

  3. 03

    Reach from anywhere

    Engineer WireGuard to the hub, then browse the cheat sheet. Optional hub LAN scan discovers hosts when the tunnel is live.

Built for fleets

  • Access log + config download audit trail

What we learned in the POC

Direct Linux / Pi WireGuard is the fastest path to a working demo. Consumer UniFi “VPN Client” is a poor gateway for inbound LAN access — prefer Teltonika or a small Linux edge with NETMAP.

Making it good

The POC proves the model. These moves turn it into an operator product.

Trusted gateway path

First-class Teltonika / Linux bring-up, health checks, and a clear “supported edge” list. Kill confusion around UniFi.

Safer installs

One-time temp links, shorter TTL options, scoped tokens for CI/cloud bootstrap, revoke-all on rotate.

Smarter discovery

Scheduled LAN scans, better type detection, optional mDNS/SNMP later — still additive, never destructive.

Operator UX

Handshake age, last reachability, per-device ping history, fleet filters, and “copy reach URL” everywhere.

Hardening & ops

Forced strong admin password, backup/restore of SQLite + PKI, alert when a site goes dark.

Pilot discipline

1–2 real sites, named engineers on 4G, runbook for join/rotate/disable — then scale catalogues and regions.

Get started

Clone the repo, bring Compose up locally (dry-run friendly on a Mac), then deploy the VPS overlay when you want real tunnels.

git clone https://github.com/knaps151/ParkTech-Relay.git
cd ParkTech-Relay
cp .env.example .env
docker compose up -d --build
