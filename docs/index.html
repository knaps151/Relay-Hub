How it works

Operators provision sites on the hub. Edge gear joins with WireGuard, Tailscale (Headscale), or OpenVPN. Techs connect to the hub and open virtual IPs from the cheat sheet.

01

Allocate

Each site gets the next 10.101.X.0/24. Local host .Y maps 1:1 to virtual .Y.

02

Connect the edge

Gateway router for a full LAN, or WireGuard on a single device — including a short-lived curl | sudo bash install link for Linux hosts.

03

Reach from anywhere

Engineers use WireGuard to the hub, then open the cheat sheet. Optional LAN scan discovers hosts when the tunnel is online.

Get started

Clone the repository and bring Compose up locally. Use the VPS overlay when you need live WireGuard and HTTPS.

Open repository 
git clone https://github.com/knaps151/Relay-Hub.git
cd Relay-Hub
cp .env.example .env
docker compose up -d --build
# Dashboard: http://127.0.0.1:8000
